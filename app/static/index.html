A Cívica é um projeto aberto de consulta e auditoria de dados públicos. O corpus cresce conforme novas bases são verificadas.

01 / PLANO

O que foi prometido?

Preservamos os documentos originais, páginas, datas, autoria e integridade por SHA-256.

02 / AÇÃO

O que foi efetivamente feito?

Diferenciamos projeto, votação, lei aprovada, orçamento pago e serviço entregue. Essas camadas ainda estão sendo integradas.

03 / IMPACTO

O que mudou?

As séries públicas têm fonte e período. Não atribuímos causalidade apenas pela coincidência temporal.

◎
Privacidade e autonomia.

O app não pede dados pessoais nem preferências políticas, não pontua políticos e não recomenda votos. Dados salvos para uso offline ficam no dispositivo.

Módulo de síntese por modelo de linguagem opcional disponível na API original. A edição web instalável usa recuperação documental e não simula uma IA generativa quando a API não está disponível.
